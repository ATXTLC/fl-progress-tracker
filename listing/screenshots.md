# Screenshot spec (capture in WoW Forever — we can't run the client)

Settings: 1920×1080 windowed, UI scale default, hide other add-ons' frames, use your own character only, blur/crop other players' names and chat.
Save as PNG, name `NN-short-name.png`, put in `listing/screenshots/`. CurseForge/Wago accept JPG/PNG; first image = gallery cover.

1. **01-addon-list.png** — Character select → AddOns window with **FL Progress Tracker** ticked and version visible (proves title/folder rename).
2. **02-fl-help.png** — Chat after typing `/fl`: the "FL Progress Tracker commands: …" line and the summary line.
3. **03-whats-new.png** — First login after install: the gold "FL Progress Tracker 1.2.0 — what's new:" chat block.
4. **04-health.png** — `/fl health` output in chat.
5. **05-errors-window.png** — `/fl errors` copy window titled "FL Progress Tracker errors - Ctrl+A then Ctrl+C to copy" (empty list is fine: then capture the "no errors recorded" chat line instead).
6. **06-watchlist.png** — `/fl watch <questId>` then `/fl watchlist` output.
7. **07-reload-saved.png** — chat line after `/reload` showing "X changed, watching …" summary.
8. **08-savedvariables-file.png** — Explorer showing `_forever_\WTF\Account\<ACCOUNT>\SavedVariables\fl-progress-tracker.lua` (blur the account folder name).
9. **09-dashboard-quests.png**, **10-dashboard-map.png**, **11-dashboard-character.png** — foreverledger.net after uploading (the existing preview_*.png in the repo can stand in; replace with real data post-launch).

Icon: `listing/icon_400.png` (400×400 PNG) — gold rounded-square outline with serif gold "FL" monogram on near-black (#15120f / #c9a24a), matching the site header mark. Replaces the earlier medallion icon.

Do NOT include: ads, donation/Ko-fi links, other players' names, BattleTags, account names.
